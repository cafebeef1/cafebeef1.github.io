# Cloud Networking Notes

个人云网络原理学习博客，基于 GitHub Pages + Jekyll。

网站：https://cafebeef1.github.io/

## 新增文章
在 `lessons/` 新建带 YAML front matter 的 Markdown 文件，设置 `layout: default`、`title`、`permalink`，并在 `lessons/index.md` 添加导航。

## 部署
`main` 分支推送后，GitHub Actions 构建并部署到 GitHub Pages。仓库 Settings → Pages 的 Source 需要选择 **GitHub Actions**。
